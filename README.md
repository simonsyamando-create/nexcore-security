# NexCore Security Premium Website

Static, mobile-first website for GitHub Pages.

## Upload
Upload the CONTENTS of this folder to the root of `simonsyamando-create/nexcore-security`. Do not upload only the ZIP.

## Publish
1. Open repository **Settings > Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then save.
4. The default address is `https://simonsyamando-create.github.io/nexcore-security/`.

## Optional video hero
Place a compressed, licensed MP4 at `assets/video/hero.mp4`. The included poster image is the automatic fallback. Keep the video short, muted, without text, and ideally below 8 MB.

## Before public launch
- Replace the demo email address.
- Connect forms to an approved processor.
- Add an approved privacy policy and terms.
- Add client logos and testimonials only with written permission.
- Keep the SCEC wording as “application in progress” until endorsement is formally awarded.
- Check every technology-brand reference and remove any platform the business does not genuinely support.

## Mobile checks
Test iPhone Safari at 320, 375, 390 and 430 px widths, landscape mode, keyboard-open forms, dark mode, reduced-motion mode and Add to Home Screen.
